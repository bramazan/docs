title: "Şehir ve İlçe"

---

İl ve ilçe lookup'ları; merchant onboarding ve adres formlarında dropdown doldurmak için kullanılır. Sayfalama yoktur — tüm il/ilçe listesi tek seferde döner.

## Şehirler

```http
GET /api/v1/lookups/cities
```

```bash
curl https://identity.payven.com.tr/api/v1/lookups/cities \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

Yanıt — şehir listesi (81 il):

```json
[
  { "id": "abc-...", "code": "34", "name": "İstanbul", "country": "TUR", "is_active": true },
  { "id": "def-...", "code": "06", "name": "Ankara",   "country": "TUR", "is_active": true },
  { "id": "ghi-...", "code": "35", "name": "İzmir",    "country": "TUR", "is_active": true }
]
```

| Alan | Açıklama |
|---|---|
| `id` | UUID |
| `code` | Plaka kodu (`34`, `06`, ...) — districts sorgusunda `city_code` filtresi olarak kullanılır |
| `name` | Türkçe isim |
| `country` | Ülke kodu (`TUR`) |
| `is_active` | Aktiflik |

Query parametreleri: `code` (plaka filtresi), `search_term`, `include_inactive`.

## İlçeler

```http
GET /api/v1/lookups/districts?city_code={plaka}
```

İlçeleri **şehir bazında** çekersiniz. Tüm ilçeleri tek seferde almak mümkün ama 950+ kayıt — seçilen şehre göre lazy-load önerilir.

```bash
curl "https://identity.payven.com.tr/api/v1/lookups/districts?city_code=34" \
  -H "Authorization: Bearer $PAYVEN_TOKEN"
```

```json
[
  { "id": "...", "city_code": "34", "name": "Kadıköy",  "is_active": true },
  { "id": "...", "city_code": "34", "name": "Beşiktaş", "is_active": true },
  { "id": "...", "city_code": "34", "name": "Şişli",    "is_active": true }
]
```

| Query parametresi | Tip | Açıklama |
|---|---|---|
| `city_code` | string | Plaka kodu filtresi (`34`) — boş bırakılırsa tüm ilçeler döner |
| `search_term` | string | İsim araması |
| `include_inactive` | bool | Pasif kayıtları da getir |

## Caching

Bu liste **çok nadir** değişir (yeni ilçe atanması nadirdir). İstemcinizde **7 günlük** cache uygulayabilirsiniz.
